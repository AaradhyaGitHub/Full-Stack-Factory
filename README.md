# Full Stack Factory 🏗️

**A builder-style, hands-on guide to React and full-stack development.**

Full Stack Factory is a personal blog and learning platform where I break down React concepts into small, functional, app-like features — treating web development like assembling Lego blocks. The goal isn't to reinvent tutorials, but to create a practical, builder’s reference that reflects how real applications behave: what happens when you click a button, submit a form, handle an error, update UI, fetch and loop through data, and so on.

Rather than teaching React the traditional “book” way — starting with definitions and theory — Full Stack Factory is meant to be a _handyman’s guide_ to React. It’s for anyone who wants to learn by building and understanding the common patterns that make modern web apps tick.

## 🚧 Why It Exists

I'm currently learning React at a fast pace, but like many, I often forget what I learned until I build something with it. Rather than letting my study notes sit unused in a GitHub folder, I decided to turn them into something more meaningful — a place where I consolidate my understanding by teaching it in my own words and style.

This is as much a resource for others as it is a tool for me to revisit and reinforce concepts. And as I grow, so will the platform.

## 📦 The Code Structure

What makes Full Stack Factory different is its **scalable and structured content model**, which mirrors real-world platforms like Codecademy or Frontend Masters.

- **Frontend-Ready Data**: Each course, unit, and lesson is structured in a way that's immediately usable by the UI. No messy transforms.
- **Extensible Model**: The course data format is designed to scale. Add another course or unit and the frontend adapts instantly.
- **Progress-Oriented Design**: With fields like `unitCount`, `lessonCount`, and `topicsCovered[]`, it's already structured for tracking completion and engagement.
- **Clean Architecture**: Features like dynamic navigation via `useParams()`, data-driven sidebars, and reusable components make the system adaptable and cleanly organized.

---

## 💡 Notable Features

- **Reusable UI components** for layout, navigation, and lesson cards
- **Dynamic routing** and rendering using `useParams()` for scalability
- **Progress scaffolding** built-in with `topicsCovered[]` and potential for `isCompleted` flags
- **Thoughtful data modeling**: 
  - `id`, `title`, `description` for indexing
  - `durationMinutes`, `resources[]` (future additions)
- **Builder-friendly lessons** that focus on hands-on functionality, not just definitions
